# zhc_bench

Part of [ZHC](https://github.com/zama-ai/zhc), the compiler toolchain for FHE computation.

This crate benchmarks the toolchain, tracking both the quality of the generated programs and the speed of the compiler. It is internal to the workspace and not published.
