# zhc_iops_l2r

Part of [ZHC](https://github.com/zama-ai/zhc), the compiler toolchain for FHE computation.

This crate lets the Lean code of `zhc_lean` call the ZHC builder. It exposes the builder and its value types through a C ABI. The matching C header is `include/zhc.h`.
